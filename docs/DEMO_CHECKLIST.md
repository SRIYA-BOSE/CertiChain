# Submission demo checklist

1. Show Fabric test-network running and channel/chaincode status.
2. Show admin login and student registration/login.
3. Admin issues a certificate PDF and assigns it to student email.
4. Show certificate record and SHA-256 hash.
5. Student portal displays assigned certificate.
6. Public QR URL opens verification page.
7. Upload exact PDF → VALID.
8. Upload modified PDF → HASH_MISMATCH.
9. Show Fabric history with transaction IDs/timestamps.
10. Revoke a disposable test record → REVOKED.
11. Show dashboard metrics and charts.
12. Explain that PDFs and user accounts are off-chain; hash/status history is on Fabric.
13. Mention API-side pagination and prototype deployment/security limitations accurately.
